# Project Apex
Project Apex is a RC racing project focused on building a complete, custom-designed racing ecosystem. It features a custom F1 RC car, a custom built controller, and a interactive racing track. The entire system is built around 3D printed components and powered by ESP32 microcontrollers.

### Car
The f1 car will be custom designed, it will be controlled with a esp32, servo and a brushless motor.
The car itself will have 4 wheels, battery, steering mechanic, gas/brake mechanic and a communication device.

### Controller
The controller will be custom designed and built to provide full control over the RC car. It will communicate wirelessly with the car using an ESP32 and feature dedicated controls for steering, acceleration and braking. The controller will include physical input components such as joysticks, buttons and/or triggers, along with a battery and a communication module to ensure reliable real-time control.

### Scoring system
The track features a sensor based scoring system that rewards racing line precision, combined with lap time tracking. Results are displayed on a monitor through a live leaderboard, allowing drivers to compete for the highest scores and fastest times.

### Tools used
Designed using Autodesk Fusion 360, programmed with Arduino, and [My Planning App](https://github.com/JoepMaas/Planning-Website)
